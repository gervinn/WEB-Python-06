# Замовлення квитків у кінотеатр

Готовий навчальний вебзастосунок на **Python + FastAPI + SQLAlchemy + SQLite** для предметної галузі **«Замовлення квитків у кінотеатр»**.

## Що реалізовано

- серверна генерація HTML через **Jinja2**;
- збереження даних у **SQLite**;
- робота з даними через **SQLAlchemy ORM**;
- щонайменше **4 сутності**:
  - `User`
  - `Movie`
  - `Showtime`
  - `Booking`
- дві ролі:
  - **адміністратор**
  - **користувач**
- повний **CRUD для сутності Movie**:
  - create
  - read
  - update
  - delete
- HTML-інтерфейс для роботи з фільмами, сеансами та бронюваннями;
- REST API з OpenAPI-документацією;
- змінено стандартну документацію OpenAPI:
  - інший заголовок
  - інший опис
  - власні теги
  - змінені маршрути документації (`/documentation`, `/reference`, `/api/openapi.json`)

## Запуск

### 1. Створити та активувати віртуальне середовище

#### Windows
```bash
python -m venv venv
venv\Scriptsctivate
```

#### macOS / Linux
```bash
python3 -m venv venv
source venv/bin/activate
```

### 2. Встановити залежності

```bash
pip install -r requirements.txt
```

### 3. Запустити застосунок

```bash
uvicorn app.main:app --reload
```

або

```bash
python run.py
```

### 4. Відкрити в браузері

- Головна сторінка: `http://127.0.0.1:8000/`
- OpenAPI Docs: `http://127.0.0.1:8000/documentation`
- ReDoc: `http://127.0.0.1:8000/reference`

## Основні можливості

### Адміністратор
- перегляд списку фільмів;
- додавання нового фільму;
- редагування фільму;
- видалення фільму;
- додавання сеансів;
- перегляд усіх бронювань.

### Користувач
- реєстрація та вхід;
- перегляд афіші;
- перегляд сеансів;
- бронювання квитків;
- перегляд власних бронювань.

## API-приклади

### Отримати всі фільми
```http
GET /api/movies
```

### Отримати один фільм
```http
GET /api/movies/{movie_id}
```

### Створити фільм (тільки адміністратор)
```http
POST /api/movies
```

### Оновити фільм (тільки адміністратор)
```http
PUT /api/movies/{movie_id}
```

### Видалити фільм (тільки адміністратор)
```http
DELETE /api/movies/{movie_id}
```

### Створити бронювання
```http
POST /api/bookings
```
